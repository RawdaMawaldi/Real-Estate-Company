# Real-Estate-Company
مشروع آمن لجدولة وإدارة حجوزات العقارات يمنع التضارب عبر الـ Polling المستمر. يضمن النظام حماية البيانات بـ JWT باستخدام frameworks المسؤولة عن استقبال الطلب واستدعاء الدالة عبر Express وإرسال الطلب عبر React، مانحاً كل user/Admin بواسطة رقم Token رقم ID خاص به وصلاحيات دقيقة. مع دعم Overriding لتطوير واجهات بتعديلات طفيفة عن النمط الأب المستخدم.
