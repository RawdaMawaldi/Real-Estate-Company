# Real-Estate-Company
مشروع يعمل على ترتيب وجدولة مواعيد حجوزات العقارات، يقوم بإدارة وتثبيت كامل عمليات الحجز المتاحة وتوصيف دقيق للمدة التي سيتاح بعدها العقار ومواصفاته كاملة، النظام يمنع أيّ وصول غير مصرّح به من قبل user/Admin عبر ضبط كلّ مشرف برقم token يحدد ال id الخاص به وصلاحيات وصوله للبيانات بدقّة عبر نقاط وصول Endpoints تربط الواجهات التفاعلية interfaces مع الكود في الخلفية Back-end بشكل آمن تماماً ويتيح استخدام نفس الكود Overriding لإنشاء واجهات جديدة بتعديلات طفيفة مختلفة عن النّمط الأب المستخدم.
وتتيح هذه الEndpoints أحياناً القراءة من حقل واحد من كامل الجدول بدون إمكانية تعديل أو إضافة أو حذف على عكس مشرفين آخرين، ممّا يعكس تحكّم كامل ودقيق ومضبوط للوصول لقاعدة البيانات أو الكود المصدري Source Code
النظام يعمل على جلب الإشعارات بشكل دوري من السيرفر باستخدام خاصيّة polling ليمنع أيّ تضارب في الحجوزات.

 يقوم إطار عمل React بإرسال طلب من نوع post للتحقق من كلّ عملية loginوصلاحياتها بشكل دقيق عبر ال token.. ويقوم framework Express باستقبال الطلب واستدعاء الدّالة المسؤولة عن تسجيل الدّخول.
وباستخدام المعيار المفتوح والشائع استخدامه لتأمين وحماية نقل البيانات بين المتصفح المحلي والسيرفر (Json Web Token)
